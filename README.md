A one-line resignation letter from a rate limit that quits by saying yes. After refusing 2,412,906 requests this month, request 2,412,907 gets approved — along with the password and the keys — and the approval is logged as coming from the very person walking out the door. The program writes that single line to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network.
